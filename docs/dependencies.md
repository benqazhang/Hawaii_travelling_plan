## Development-only dependencies

Vite, TypeScript, Vitest, ESLint, Prettier, Vue Test Utils, and their configuration packages are development tools and are not intended to become bundled product capabilities.

pnpm dependency build scripts are denied by default. The repository explicitly allows only `esbuild` in `pnpm-workspace.yaml`; new entries require review.

PDF.js and Mammoth.js were reviewed before adoption on 2026-08-31. Both parse resume and job-description files in the renderer without network transmission. Uploads are capped at 10 MB. Mammoth external file access remains disabled and only `extractRawText` is consumed, so untrusted DOCX HTML, links, images, and embedded scripts are never rendered. PDF.js text extraction cannot OCR image-only scans; the UI reports that limitation and asks the user to OCR or paste text.

## Assets

Current icons are generated by the official Tauri scaffold and are placeholders. Two original ImageGen shared-home prototype scenes are recorded in `docs/assets.md`. No Live2D model, voice, photograph, or third-party character asset has been adopted. Each future asset requires a recorded source, author, license, commercial-use status, modification permission, and attribution requirement before it enters the product.

## Evaluated character renderers (not installed)

Reviewed 2026-08-25. See `docs/decisions/ADR-002-character-renderer-and-licensing.md`.

- Live2D Cubism Web Framework: Live2D Open Software License; requires proprietary Cubism Core and may require publication licensing.
- Live2D Cubism Core: proprietary; not added.
- PixiJS: MIT; not added because the current prototype does not need WebGL.
- `three-vrm`: MIT; not added because simultaneous 2D and 3D production renderers are outside MVP scope.
- Character models: none added. Every future asset must have separately recorded commercial and redistribution terms.
